# Historical Water Lilies qualification reference

The original development plan and its issue discussions are retained in the
[private archive](https://github.com/aberson/on-brand-private/blob/master/documentation/inspiration-real-artwork-demo-plan.md).
This public reference exists so the released example's byte-pinned provenance
document continues to resolve its relative documentation link.

The public demo contains the exact accepted image, tokens, guide, trace, and
generated outputs. Its [acceptance record](findings/inspiration-real-artwork-demo/acceptance.md)
transcribes the selected source, both review decisions, viewport checks, and
digests. The original `PROVENANCE.md` is preserved byte-for-byte; its historical
`aberson/on-brand/issues/69` and `/72` links predate the repository split.
Use these updated archive links for the original records:

- [M3a selection: issue 69](https://github.com/aberson/on-brand-private/issues/69).
- [M3b acceptance: issue 72](https://github.com/aberson/on-brand-private/issues/72).

The archive requires maintainer access. Using the tool or running public tests
requires neither the archive nor the old issue records; tests use the committed
transcriptions. See the [architecture guide](../docs/architecture.md) for current
behavior and [publication notes](../docs/publication.md) for the privacy boundary.
