What this is (and why it's seed-level, not a full specimen)

You're building an independent reference the benchmark scores against — not approving a generated brand. The M1 specimen (type scale, ramps, chart colours, components) is a deterministic expansion of a tiny seed; the only thing extracted from a site — and the only thing worth human ground-truth — is that seed: accent, backgrounds, fonts.

The mini-specimen in each card's colour stage is rendered purely from your pinned hexes (this sheet's own CSS) — never the on-brand tool's output, which is deliberately withheld (judging your pin against the tool's aesthetic would contaminate the ground truth). It's the "does this read as the brand" view, done safely.

How to sign off

  1. Accept everything: pin all — recommended value for every field (colours + fonts) + option A for each ⚖ fork.
  2. Accept with exceptions: pin all except <id>=<value>, … — e.g. pin all except imprintgenius/accent=B, spotify/light=null. Each field shows its id (in Zone B).
  3. Site by site: stripe: ok, github: accent B.

GOLD vs ACCENT — they can be the same, and usually are: accent = the site's true on-screen accent (the tool's per-site scoring target). gold = the brand's independently-published hex (the scorer's non-circular calibration anchor — a gold-matched proposal must score high, proving the metric isn't garbage). For a well-branded site the two are the SAME value (Duolingo's Feather Green #58cc02 is both its true accent and its published hex). They diverge only when a site drifts from its published guide — see imprintgenius: live-navy accent #060640 vs 2021-guide gold #4343FF.
